# Description

## zh

把 Claude Code 组织成游戏开发工作室的技能与代理体系，覆盖设计、架构、美术、平衡和制作流程。

## en

A skill and agent system that organizes Claude Code as a game-development studio across design, architecture, art, balancing, and production.

# Long Description

## zh

仓库提供数十个游戏开发工作流技能和分工明确的代理角色，用于协调大型制作任务。它能生成计划和资产规范，但玩法质量、版权、引擎兼容性与性能仍需团队验证。

## en

The repository provides many game-development workflow skills and specialized agent roles for coordinating large productions. It can generate plans and asset specifications, while teams must validate gameplay quality, rights, engine compatibility, and performance.

## en

# Usage

## zh

提供引擎、平台、范围和风格约束，先选择少量相关角色。使用实际构建和试玩验证生成方案，避免一次扩大到完整项目。

## en

Provide engine, platform, scope, and style constraints and start with a few relevant roles. Validate plans with real builds and playtests before expanding to the full project.

## en
