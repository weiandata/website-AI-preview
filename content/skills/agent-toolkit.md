# Description

## zh

开发、文档、规划与专业工作流的编码代理技能合集。

## en

A coding-agent skill collection for development, documentation, planning, and professional workflows.

# Long Description

## zh

仓库以标准 SKILL.md 提供可安装工作流。逐个检查子技能的命令、许可证和外部访问，只安装任务需要的部分。

## en

The repository provides installable workflows through standard SKILL.md files. Review each child skill's commands, license, and external access, and install only what the task needs.

## en

# Usage

## zh

先在非生产环境选择匹配任务的技能，并限定输入与权限。逐个检查子技能的命令、许可证和外部访问，只安装任务需要的部分。

## en

Start in a non-production environment with task-matched skills and bounded inputs and permissions. Review each child skill's commands, license, and external access, and install only what the task needs.

# Workflow

## zh

1. 选择任务对应的技能
2. 核对输入、权限和预期输出
3. 审阅结果后再应用或发布

## en

1. Select the skill for the task
2. Check inputs, permissions, and expected outputs
3. Review results before applying or publishing
