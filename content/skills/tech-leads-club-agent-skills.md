## en

# Long Description

## zh

仓库提供跨多种代理平台的技能目录，便于发现并安装针对具体工程任务的能力。 聚合库的认证不替代本地审查；安装前检查所选子技能、许可证、命令和外部访问范围。

## en

The repository offers a cross-agent catalog for discovering and installing capabilities tied to specific engineering tasks. Registry validation does not replace local review; inspect each selected skill, license, command, and external-access scope before installation.

# Usage

## zh

先在非生产环境选择与任务匹配的技能，提供明确输入和边界。聚合库的认证不替代本地审查；安装前检查所选子技能、许可证、命令和外部访问范围。

## en

Start in a non-production environment with the task-specific skill and explicit inputs and boundaries. Registry validation does not replace local review; inspect each selected skill, license, command, and external-access scope before installation.

## en

3. Review results before applying or publishing
