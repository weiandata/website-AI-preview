# Long Description

## zh

仓库把多个金融工作流整理为可安装技能，便于从数据收集推进到结构化分析。 技能输出不构成投资建议；关键指标、时间戳和计算必须由当前一手数据复核。

## en

The repository packages multiple financial workflows as installable skills, moving from data collection to structured analysis. Skill outputs are not investment advice; verify key metrics, timestamps, and calculations against current primary data.
