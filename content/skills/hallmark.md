# Description

## zh

反模板化设计技能，帮助编码代理避免常见的低质量 AI 界面模式。

## en

An anti-slop design skill that helps coding agents avoid common low-quality AI interface patterns.

# Long Description

## zh

该技能聚焦视觉判断与界面细节，适合在实现或评审阶段减少千篇一律的组件、配色和版式。它提供审美约束，但最终方向仍需符合产品、品牌和用户需求。

## en

The skill focuses on visual judgment and interface detail to reduce generic components, colors, and layouts during implementation or review. It supplies aesthetic constraints, while the final direction must fit product, brand, and user needs.

# Features

## zh

- 识别常见 AI 界面套路
- 改进视觉层级和细节

## en

- Identifies common AI interface clichés
- Improves visual hierarchy and detail

# Use Cases

## zh

- 评审生成式前端页面
- 优化缺乏辨识度的界面

## en

- Review a generated frontend page
- Improve an interface that lacks identity

npx skills add Nutlope/hallmark

# Usage

## zh

提供产品目标、品牌材料和目标用户。让技能指出具体问题并给出可比较方案，而不是只做无依据的视觉变化。

## en

Provide product goals, brand material, and target users. Ask for specific problems and comparable alternatives rather than unsupported visual changes.

# Workflow

## zh

1. 提供界面和品牌上下文
2. 识别模板化设计问题
3. 实施并进行用户视角复核

## en

1. Provide interface and brand context
2. Identify generic design problems
3. Implement and review from the user's perspective

# FAQ

## Question 1

### question.zh

反模板化是否意味着必须做复杂设计？

### question.en

Does anti-slop design require complexity?

### answer.zh

不意味着。目标是有意图、适合产品的设计，简单界面同样可以清晰而有辨识度。

### answer.en

No. The goal is intentional, product-appropriate design; simple interfaces can still be clear and distinctive.
