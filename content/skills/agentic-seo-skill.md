## en

# Long Description

## zh

该仓库提供一个可安装的 SEO 技能，并列出 Claude Code、Codex、Cursor、Antigravity 与 Windsurf 等环境。它适合把页面审查、内容策略和技术 SEO 任务交给代理协助完成。由于搜索规则与站点数据会变化，应结合当前搜索引擎官方文档、Search Console 或同类数据，以及发布后的实际指标验证建议。

## en

The repository provides an installable SEO skill and lists environments including Claude Code, Codex, Cursor, Antigravity, and Windsurf. It supports page review, content strategy, and technical SEO tasks. Because search rules and site data change, validate recommendations against current search-engine documentation, Search Console or equivalent data, and post-release measurements.

# Usage

## zh

安装后提供目标网址、受众、市场、业务目标和可用搜索数据。要求代理区分事实、推断和建议，并为每项修改指定可观察指标；发布后持续比较排名、点击和转化变化。

## en

After installation, provide the target URL, audience, market, business goal, and available search data. Require the agent to separate facts, inferences, and recommendations and to name an observable metric for each change; compare rankings, clicks, and conversions after release.

# FAQ

## Question 1

### question.zh

使用这个技能能保证排名提升吗？

### question.en

Does using this skill guarantee higher rankings?

### answer.zh

不能。它能改进分析和执行流程，但排名还受竞争、站点权威、内容质量、技术状态和搜索系统变化等因素影响。

### answer.en

No. It can improve analysis and execution, but rankings also depend on competition, site authority, content quality, technical health, and changes in search systems.
