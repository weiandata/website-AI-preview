# Description

## zh

基于 Obsidian 与纯 Markdown 的自组织第二大脑技能，将输入资料读取、链接并归档到知识图谱。

## en

A self-organizing Obsidian second-brain collection that reads, links, and files sources into a plain-Markdown knowledge graph.

# Long Description

## zh

仓库提供保存、思考、Canvas、Bases 和内容提取等技能，强调本地可拥有的知识文件。导入资料时仍要保护隐私、核对来源，并在批量重组前备份 Vault。

## en

The repository provides saving, thinking, Canvas, Bases, and extraction skills around locally owned knowledge files. Protect privacy, verify sources, and back up the vault before bulk reorganization.

# Features

## zh

- 自动链接和归档知识材料
- 数据保存在纯 Markdown Vault

## en

- Links and files knowledge sources
- Keeps data in a plain-Markdown vault

# Use Cases

## zh

- 构建研究或个人知识库
- 将零散材料整理为关联笔记

## en

- Build a research or personal knowledge base
- Organize scattered sources into linked notes

# FAQ

## Question 1

### question.zh

资料会自动变得可信可靠吗？

### question.en

Does organization make source material trustworthy?

### answer.zh

不会。归档与链接不等于事实核验，重要结论仍需回到原始来源。

### answer.en

No. Filing and linking do not verify facts; important claims still need original sources.
