# Long Description

## zh

技能组织产业链、瓶颈、公司暴露度与证据检查，适合形成可追溯的初步研究框架。 内容不构成投资建议；价格、财报和行业数据必须使用当前一手来源复核，并明确不确定性。

The skill organizes value chains, bottlenecks, company exposure, and evidence checks into a traceable preliminary research framework. This is not investment advice; verify prices, filings, and industry data with current primary sources and state uncertainty.
