# Description

## zh

让编码代理减少铺垫、突出结论并采用更适合 ADHD 用户阅读的输出结构。

## en

Makes coding-agent output less buried, more conclusion-first, and easier for users with ADHD to scan.

# Long Description

## zh

该技能改变回答组织方式，强调短段落、明确行动和减少无关解释。它不会改变任务本身的技术要求，高风险决定仍应保留必要细节和证据。

## en

The skill changes response organization through short sections, explicit actions, and less irrelevant explanation. It does not alter technical requirements, and high-risk decisions still need necessary detail and evidence.

# Features

## zh

- 结论和行动优先
- 减少冗长铺垫

## en

- Prioritizes outcomes and actions
- Reduces lengthy preambles

# Use Cases

## zh

- 获取快速可执行的开发答复
- 压缩冗长的状态报告

## en

- Get fast, actionable development answers
- Compress lengthy status reports

# Installation

```bash
npx skills add ayghri/i-have-adhd
```

# Usage

## zh

安装后说明希望的详细程度和必须保留的信息。若任务涉及安全、法律或财务风险，不要为了简短省略关键证据。

## en

After installation, state the desired detail level and required information. For security, legal, or financial risks, do not omit essential evidence merely for brevity.

# Workflow

## zh

1. 设定输出长度与重点
2. 先给结论和行动
3. 按需展开证据

## en

1. Set output length and priorities
2. Lead with outcome and action
3. Expand evidence when needed
