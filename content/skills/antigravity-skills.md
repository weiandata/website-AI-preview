## en

# Long Description

## zh

仓库以标准 SKILL.md 组织大量可安装能力，可按具体任务选择而无需一次加载全部内容。 大型合集需逐个审查子技能；安装前核对许可证、命令、外部访问与上下文成本。

## en

The repository organizes many installable capabilities as standard SKILL.md files so agents can select only what a task requires. Review each child skill in this large collection; check licenses, commands, external access, and context cost before installation.

# Usage

## zh

先在非生产环境选择与任务匹配的技能，提供明确输入和边界。大型合集需逐个审查子技能；安装前核对许可证、命令、外部访问与上下文成本。

## en

Start in a non-production environment with the task-specific skill and explicit inputs and boundaries. Review each child skill in this large collection; check licenses, commands, external access, and context cost before installation.
