# Description

## zh

为建筑实践设计的 Claude 技能合集，覆盖设计分析、项目文档和建筑专业工作流。

## en

A Claude skill collection designed for architectural practice, covering design analysis, project documentation, and profession-specific workflows.

# Long Description

## zh

该仓库通过 Claude 插件市场分发一组面向建筑师的技能，将建筑项目中的重复研究、整理和文档任务变成结构化流程。它适合辅助专业工作，但不能替代持证人员的判断、当地法规核查或工程计算。任何面向客户、报批或施工的输出都应由相应专业人员审核。

## en

The repository distributes architecture-focused skills through a Claude plugin marketplace, turning recurring research, organization, and documentation tasks into structured workflows. It supports professional work but does not replace licensed judgment, local-code checks, or engineering calculations. Appropriate professionals should review anything intended for clients, permitting, or construction.

# Usage

## zh

安装后提供项目阶段、地点、建筑类型、交付物和适用标准。明确哪些内容仅供概念研究，哪些需要专业签署；在对外使用前核对法规、尺寸、来源和责任边界。

## en

After installation, provide the project phase, location, building type, deliverables, and applicable standards. Distinguish conceptual research from material requiring professional sign-off, and check codes, dimensions, sources, and responsibility boundaries before external use.

# Workflow

## zh

1. 添加市场并安装建筑技能
2. 提供项目阶段与所在地信息
3. 指定交付物和适用标准
4. 生成研究、分析或文档草稿
5. 由对应专业人员审核

## en

1. Add the marketplace and install the architecture skills
2. Provide project phase and location
3. Specify deliverables and applicable standards
4. Generate research, analysis, or document drafts
5. Have the relevant professional review them

# FAQ

## Question 1

### question.zh

技能输出可以直接用于报批或施工吗？

### question.en

Can skill output be used directly for permitting or construction?

### answer.zh

不能直接使用。法规、工程安全和专业责任取决于项目所在地与具体条件，必须由具备相应资质的人员审核和签署。

### answer.en

Not directly. Codes, engineering safety, and professional responsibility depend on location and project conditions, so qualified professionals must review and sign off.
