# Description

## zh

HTML 原生设计技能，用于高保真原型、幻灯片、动画、设计评审和媒体导出。

## en

An HTML-native design skill for high-fidelity prototypes, slides, animation, design review, and media export.

# Long Description

## zh

华述设计将多种设计哲学与五维评审方法融入一个可跨代理使用的技能。它适合快速创建可运行视觉成果，但品牌一致性、可访问性和真实内容表现仍需人工检查。

## en

Huashu Design combines multiple design philosophies with a five-dimensional review method in an agent-agnostic skill. It accelerates runnable visual output, while brand consistency, accessibility, and real-content behavior need human review.

# Features

## zh

- 以 HTML 创建可运行设计
- 支持原型、幻灯片和动画

## en

- Creates runnable designs in HTML
- Supports prototypes, slides, and animation

## en

# Usage

## zh

提供受众、品牌、内容和输出尺寸。先确认单页方向，再扩展完整作品，并检查响应式、键盘操作和导出质量。

## en

Provide audience, brand, content, and output dimensions. Approve one page before expanding the full work, then inspect responsiveness, keyboard use, and export quality.

# Workflow

## zh

1. 定义内容与视觉约束
2. 生成并评审样页
3. 扩展并验证导出

## en

1. Define content and visual constraints
2. Generate and review a sample
3. Expand and verify exports
